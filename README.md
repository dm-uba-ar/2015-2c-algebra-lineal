# **RÉGIMEN DE APROBACIÓN DE LA MATERIA**

\
- **Régimen de promoción**.
  Para aprobar las prácticas se deben aprobar dos exámenes parciales. Para los alumnos que desaprueben alguno o ambos de estos exámenes, habrá dos fechas de recuperación al finalizar el cuatrimestre. En ambas fechas se toman recuperatorios del primer y segundo parcial. Un alumno que aprueba un parcial y desaprueba el otro, puede utilizar, si es necesario, las dos fechas de recuperación para recuperar el parcial que desaprobó. Un alumno que desaprueba ambos parciales puede elegir en qué fecha de recuperación recupera cada parcial, pero no es posible recuperar ambos parciales en una misma fecha.
  \
- **Inscripción**. Para poder ser incluido en las Actas, en caso de aprobar los trabajos prácticos, es necesario haberse inscripto en la materia (a través del [Sistema de Inscripciones de la Facultad](http://www.inscripciones.fcen.uba.ar/)) y haber completado la encuesta de evaluación docente.
